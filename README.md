# 🪙 MyToken DApp

A decentralized token sale application built on Ethereum. This project demonstrates how to create, sell, and manage custom ERC-20 tokens with a KYC (Know Your Customer) mechanism to control participation.

---

## ⚡ Description

This DApp allows users to purchase tokens directly through a web interface once they complete KYC verification.  
The system is composed of three main smart contracts:

1. **MyToken** – ERC-20 compliant token.
2. **TokenSale** – Manages the purchase of tokens.
3. **KycContract** – Controls user eligibility for token purchases.

It provides a full-stack blockchain implementation with Web3.js integration on the frontend.

---

## 🛠️ Tech Stack

- **Smart Contracts**: Solidity, OpenZeppelin  
- **Blockchain Network**: Ethereum (Sepolia Testnet)  
- **Frontend**: React.js, Context API  
- **Web3 Integration**: Web3.js  
- **Development Tools**: Truffle, Ganache  

---

## ✨ Key Features

- 🔐 **KYC Verification** – Restrict token purchases to verified users only.  
- 💸 **Token Sale** – Buy tokens using Ether (1 Wei = 1 Token for demo purposes).  
- 🪙 **ERC-20 Token** – Custom token implementation following ERC-20 standard.  
- 🌍 **Blockchain Integration** – Connects to Ethereum via MetaMask or Web3 provider.  
- ⚡ **Real-Time Updates** – Reflects account and contract interactions dynamically in the frontend.
